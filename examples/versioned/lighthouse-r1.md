# SaPP Core: 雨の日だけ歌う灯台

Name: 雨の日だけ歌う灯台

One-liner: 雨の日だけ、海へ古い歌を流す灯台。

Core Rules:

- 灯台は雨の日だけ歌う
- 歌は何かを忘れないために流れる
- 歌の由来は未解決のままにする

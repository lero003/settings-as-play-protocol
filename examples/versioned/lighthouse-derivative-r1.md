# SaPP Core: 雨の日の灯台放送

Name: 雨の日の灯台放送

One-liner: 灯台の古い歌を、海辺の町のラジオ番組として描く。

Core Rules:

- 灯台は雨の日だけ歌う
- 歌は何かを忘れないために流れる
- 歌の由来は未解決のままにする

Variables: 放送する町 / 聞く人物 / 番組の長さ

What Changed: medium becomes a radio story; What Stayed: all three Core Rules.
